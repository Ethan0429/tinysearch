# TinySearch

Chrome and Firefox extension that brings sourced research answers into
[DGG bigscreen](https://www.destiny.gg/bigscreen) chat.

Research appears as short **TinySearch** summaries, shown in full with up to two
source links. Choose **Full answer** to read the details, all sources, and the
original stream moment in the history panel.

## Using the extension

- Open **TinySearch** above chat to search previous questions and answers.
- Use **Older / Newer** or the toolbar arrows to browse answers.
- Click the clipboard button in chat to copy the summary with an `@Destiny `
  prefix, ready to paste yourself. The summary allows 280 characters of prose;
  the prefix and up to two source URLs are outside that limit. The detail panel copies the full answer.
- Use **This stream** to filter history when watching a YouTube stream.
- Use the extension popup to enable research, show or hide messages in chat,
  and choose card spacing.
- Enable **Answers on other tabs** in the popup for a translucent notification
  at the bottom right of the active tab in your focused browser window. This is
  off by default and asks for optional website access when enabled.

Earlier answers stay in history when you open a tab. New answers appear alongside
the conversation. Full answers link to their original stream and all sources.

Notifications show the same summary and source links as chat. They dismiss after
12 seconds, pause while hovered or focused, and include a copy button prefixed
with `@Destiny `. DGG keeps its existing chat cards. Browser settings, extension
stores, PDF viewers and other protected pages cannot show these overlays.
Background checks run about every 30 seconds with DGG closed; browser sleep or
background throttling can delay them. Enabling notifications does not replay old
answers. Turn the option off to dismiss notifications and remove the optional
website access.

## Updates and changelog

Chrome Web Store installations update through Chrome. The popup can check the store on demand. When Chrome reports a downloaded update, TinySearch shows a **NEW** badge and an **Update** link above DGG chat. Restart Chrome to apply a pending update immediately.

Firefox checks GitHub releases. Download the Firefox ZIP, replace the loaded extension files, and reload it. Both browsers include **What’s new** in the popup.

The [live dashboard](https://tinysearch.app) shows
questions, answers, latency, and costs.

## Installation

### Chrome

Install [TinySearch from Chrome Web Store](https://chromewebstore.google.com/detail/tinysearch/lgonddigopjaghgljjhjokpkpglcaboc), then open or reload DGG bigscreen.

### Firefox (142+)

Download and extract the Firefox ZIP from [Releases](https://github.com/Ethan0429/tinysearch/releases/latest).

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on** and select `manifest.json` in the extracted
   Firefox folder (or `dist/firefox` from a local build).
3. Open or reload bigscreen. Temporary add-ons remain until Firefox restarts.

## Development

Requires Node.js 22+ and npm.

```sh
npm ci
npm run check
```

Builds are written to `dist/chrome`, `dist/firefox`, and ZIPs in `artifacts/`. For Chrome development, enable Developer mode at `chrome://extensions`, choose **Load unpacked**, and select `dist/chrome`. Reload the unpacked extension after rebuilding.

```sh
npm run preview
```

Open `http://localhost:8792` for an interactive chat preview, or
`http://localhost:8792/popup` to preview the extension popup. The actual notification
renderer is available at `http://localhost:8792/notifications` with demonstration data.

## About

The extension reads the public research feed from tinysearch.app. Search and
display preferences are handled locally; see [Privacy](PRIVACY.md).

TinySearch is an independent project. Answers are generated by AI;
use the linked sources to check them.

Chat summaries allow up to 280 characters of prose. The `@Destiny ` mention and up to two source URLs are outside that limit. Answer details support Markdown emphasis, lists, tables, quotes and code. Interface icons use locally bundled Lucide SVGs.


## Supported streams

TinySearch shows research for the YouTube or supported Kick channel embedded in DGG bigscreen. Kick answers open the channel without seeking controls. Optional notifications show new answers from monitored channels while browsing other sites. Channel configuration is managed by the backend administrator in the dashboard.
