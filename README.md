# TinySearch

Chrome and Firefox extension that brings sourced research answers into
[DGG bigscreen](https://www.destiny.gg/bigscreen) chat.

Research appears as short **TinySearch** summaries, shown in full with up to two
source links. Choose **Full answer** to read the details, all sources, and the
original stream moment in the history panel.

## Using the extension

- Open **TinySearch** above chat to search previous questions and answers.
- Use **Older / Newer** or the toolbar arrows to browse answers.
- Click the clipboard button in chat to copy the summary with an `@Destiny `
  prefix, ready to paste yourself. The copied post fits within 280 characters,
  including the prefix and URLs. The detail panel copies the full answer.
- Use **This stream** to filter history when watching a YouTube stream.
- Use the extension popup to enable research, show or hide messages in chat,
  and choose card spacing.

Earlier answers stay in history when you open a tab. New answers appear alongside
the conversation. Full answers link to their original stream and all sources.

## Installation

Download and extract the browser ZIP from [Releases](https://github.com/Ethan0429/tinysearch/releases/latest).

### Chrome / Chromium (120+)

1. Open `chrome://extensions` and enable **Developer mode**.
2. Choose **Load unpacked** and select the extracted Chrome folder containing
   `manifest.json` (or `dist/chrome` from a local build).
3. Open or reload bigscreen.

### Firefox (142+)

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on** and select `manifest.json` in the extracted
   Firefox folder (or `dist/firefox` from a local build).
3. Open or reload bigscreen. Temporary add-ons remain until Firefox restarts.

## Development

Requires Node.js 22+ and npm.

```sh
npm ci
npm run check
```

Builds are written to `dist/chrome`, `dist/firefox`, and ZIPs in `artifacts/`.

```sh
npm run preview
```

Open `http://localhost:8792` for an interactive chat preview, or
`http://localhost:8792/popup` to preview the extension popup.

## About

The extension reads the public research feed from the Railway relay. Search and
display preferences are handled locally; see [Privacy](PRIVACY.md).

TinySearch is an independent project. Answers are generated by AI;
use the linked sources to check them.
