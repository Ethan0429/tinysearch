Required host access to https://tinysearch.app/* retrieves public answers and release information. The DGG chat content script inserts the chat interface and reads the embedded stream identifier locally for filtering. Optional http://*/* and https://*/* access is requested only when the user enables Answers on other tabs. It allows the packaged notification script to display public answer summaries in the active browser tab. The active tab URL is checked locally to skip DGG and protected pages; unrelated page content is not read. Native chat messages, drafts, account data, browsing URLs, search text and video identifiers are not transmitted.
