TinySearch requests https://discord-relay-production-861c.up.railway.app/v1/answers to retrieve the public research answers displayed in DGG chat, and https://tinysearch.up.railway.app/v1/extension to retrieve public release notes and update notices. Host access is restricted to these two HTTPS services. The content script runs only on https://www.destiny.gg/embed/chat* and https://destiny.gg/embed/chat* to add the TinySearch interface and identify the embedded stream locally for filtering. It does not transmit native chat messages, chat drafts, search text, account data, or current video identifiers.
